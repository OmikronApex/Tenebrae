- (direction) User: retroactive project-level spec distilled from README, AGENTS, CONTRIBUTING, architecture spine, milestone specs; output beside spec-m3b-sparse-voxel-grid. Rich input -> express distill, no elicitation.
- (decision) Slug 'tenebrae': spec covers the whole project; milestone specs stay the per-feature layer under it.
- (note) Why: a consumer project needs new occlusion tomes for a shipped engine that loads Umbra 3.3.6 v18 tomes; the only baker is Umbra's proprietary optimizer (Unity 5.1.1) and the only query code is the engine's own runtime. Tenebrae is an open, pure-Rust replacement for both.
- (capability) CAP-1 Read and write any Umbra 3.3.6 v18 tome losslessly, writer recomputing every derived structure. Success: byte-identical round trip on 26/26 stock tomes and 4/4 Unity 5.1.1 bakes (M1).
- (capability) CAP-2 Exact segment occlusion against a triangle soup as visibility ground truth. Success: truth tool and bench scoring use it; 784k segments vs 10 M triangles in 2.4 s (M2).
- (capability) CAP-3 Bake a tome from occluder geometry that the engine's runtime answers correctly. Success: parity scene, 586 captured engine views: every status 0, 0 truly visible objects culled (M3).
- (capability) CAP-4 Bake at or below Umbra's cost: memory, time, tome size. Success: parity scene 65-78 s / +200 MB on 16 threads vs Umbra 164-359 s / +1,577 MB; 667,168 B vs Umbra 1,284,240 B; bench smaller than Umbra on 35/40 cases (M3b, size parity).
- (capability) CAP-5 Incremental re-bake from a per-tile cache. Success: cached re-bake byte-identical to fresh; parity scene unchanged 2.4 s vs fresh 66 s, one prop moved 4.9 s (M3c).
- (capability) CAP-6 Versioned consumer bake API (contract v2): instanced or soup occluders, targets with user lists, one view volume in; tome, object map, cell points, report, cache out; progress with cancel; presets. Success: default bakes byte-identical to M3c; instanced == applied soup bytes; keep_every_target maps object i = target i (M4).
- (capability) CAP-7 Native frustum and portal queries over a decoded tome, clean-room. Success: vs engine native runtime on 1,029 captured views statuses and frustum lists equal, 0 truly visible culled on bench truth, objects kept within +10 % (measured +3 to +6.5 %); median query <= 1.5x engine's (measured 2.1x, open) (M6).
- (capability) CAP-8 Self-contained benchmark with gates needing nothing outside the repo: 8 generated scenes + Bistro (CC BY 4.0) + Sponza (CC BY 3.0) at 8/16/32/64 m tiles; Umbra's own numbers committed as reference. Success: cargo test -p tenebrae-bench passes round trip, determinism, cache, instanced=soup, size vs baseline, visibility vs ray-cast truth.
- (capability) CAP-9 Query cost in the engine's own runtime no worse than Umbra's tomes. Success: portal queries 13 % faster than on Umbra's tomes, 11 % faster with LOD tiles, objects kept +0.2 %, no new false cull.
- (constraint) Library crates pure (AD-1): no fs/net/process/GPU/env/clock, no deps outside workspace, no unsafe; I/O only in tenebrae-tools. Reason: consumer's core crates ban I/O and threading crates.
- (constraint) Dependency directions fixed (AD-2): tome, geom -> nothing; bake -> tome, geom; runtime -> tome; facade -> all; tools/bench -> facade.
- (constraint) Runtime written from format docs and typed model only; no code derived from a proprietary runtime (AD-13 superseded: oracle deleted 2026-10-13).
- (constraint) No game data in repo; tests read tomes from TENEBRAE_TOMES and pass vacuously without (AD-4).
- (constraint) Deterministic output: same input+params -> same bytes across runs, thread counts, cache states (AD-5).
- (constraint) Acceptance by equality or parity with the engine's own runtime via external harness; never self-validated (AD-4).
- (constraint) One sync call per view volume -> one tome; threads only inside the call via std::thread::scope; 1 thread spawns nothing (AD-7).
- (constraint) Engine world space, metres, f32; invalid input returns typed Err, never panics (AD-6, AD-9).
- (constraint) Breaking change to contract items = new contract version named in README; new Params/Report fields not breaking (AD-10).
- (constraint) Toolchain pinned 1.97.1, edition 2024, MSRV 1.95; fmt + clippy -D warnings gate every commit. License GPL-3.0-or-later.
- (decision) Non-goals: other Umbra/format versions; encoding the visibility record, its key table or +0x30 (consumer owns); baker emitting gates or plane BSP leaves; multi-view-volume bakes; service/deployment; GPU; engine tag/key knowledge.
